# Exact motion studies — use these files

The earlier `01–04` files were generic approximations and are deprecated. Use only the `exact-*` files.

- `exact-01-eagent-light.html`: two circular 60vw light layers sharing a sin/cos center; soft-light foreground; five-second scale breathing.
- `exact-02-counter-grid.html`: orthographic wall of differently sized rectangular grids, five local scan speeds, horizontal wrap and multiply noise.
- `exact-03-profile-type.html`: existing Profile implementation—15 rows, -15 degrees, alternating directions, 12–35.8 second durations.
- `exact-04-redandgreen-fragments.html`: 36 samples arranged as a 6×6 instanced field, each independently displaced by oscillation and noise, with tangent-like source distortion.

These are isolated mechanisms, not a homepage design. Claude Design should inspect them individually and choose rather than combine all four automatically.
