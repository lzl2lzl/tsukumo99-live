# TSUKUMO99 LIVE — DICE AWAY

演唱会企划的静态占位网站。

## 当前内容

- 响应式首页，适配手机和电脑
- 红色主视觉海报
- 右下角应援角色不使用圆形容器，点击后荧光棒 GIF 只播放一轮，并保留光效和 `+1` 反馈
- 不依赖框架或外部字体，可直接部署到 GitHub Pages

## 本地预览

直接打开 `index.html` 即可查看。若浏览器限制本地资源，也可以在目录中启动任意静态文件服务器。

## 部署到 GitHub Pages

1. 将本仓库推送到 GitHub。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 `main` 分支和 `/ (root)` 目录并保存。

之后继续替换或增加网站内容不会改变已有的 Pages 链接。
